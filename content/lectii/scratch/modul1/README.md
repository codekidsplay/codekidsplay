## Ce acoperă Modulul 1 (harta Scratch)

| Zonă Scratch | Unde |
|--------------|------|
| Interfață, scenă, fundaluri, costume | L1–L2 |
| **Steagul verde** ca regulă de start (din prima oră) | L1+; L4 = reset + click pe personaj |
| Mișcare + X/Y | L3, L7 |
| Aspect (spune, mărime, culoare, costum) | L5 |
| Sunet | L6 |
| Control: `repetă` + `așteaptă` | L8 (nucleu) |
| Control: `forever` (doar animație de decor) | Bonus L5 / L8 |
| Ricoșeu: `dacă atinge marginea, sari înapoi` | Bonus L9 (fără lecție de Detectare) |
| Capstone modul | L9 mini-proiect + L10 completare / prezentare |

**Nu în M1 (vin mai târziu):** dacă…atunci, variabile, operatori, mesaje, clone, extensii.

## Note profesor (fine-tuning M1)

1. **Steagul** se folosește din L1 ca „regulă de bază”, nu aștepta L4 ca să pornească proiectele.  
2. **`forever`** rămâne la Bonus — nucleul L8 e `repetă N` ca să existe final clar (`Gata!`).  
3. **Ricoșeul pe margine** e Bonus la L9: motivant, fără să deschizi categoria Detectare.  
4. La L10: întâi **completează L9**, apoi prezentări scurte (≤10 elevi).
