# Template lecție Scratch (Code Kids Play)

**Public:** 8–10 ani · **Durata orei:** ~2 ore în clasă  
**Scop:** același schelet pe toate lecțiile M1–M5 — copilul știe la ce să se aștepte, tu scrii mai rapid.

---

## Decizii fixe (luate pentru CKP)

| Decizie | Alegere | De ce |
|--------|---------|--------|
| **Ton** | **Tu** direct, clar, fără mascotă obligatorie | Deja folosit în L1; mascota poate apărea opțional mai târziu, nu blochează scrierea |
| **Lungime** | **Text scurt** + checklist + culori de blocuri Scratch | Copiii mici citesc puțin; capturi/GIF se adaugă treptat (nu așteptăm video ca să scriem) |
| **Verificare progres** | **Checklist „De făcut azi”** la fiecare lecție + **mini-proiect** la L9 / final de modul | Quiz scurt opțional la **Recap**; nu forțăm quiz la fiecare oră |
| **EN / RO** | **Română întâi**; termenul Scratch EN **o dată + explicație** (sau pastilă colorată) | Ex: *personaj* (în Scratch: *sprite*); *mesaj* (*broadcast*); *clonă* (*clone*) |
| **Culori blocuri** | Pastile HTML ca în L1 (`Mișcare` albastru etc.) | Consistență vizuală cu Scratch |
| **„Greu”** | Doar la **intro de modul**, nu în titlul fiecărei lecții | Motivare, nu intimidare |

**Glosar scurt (folosit pe tot parcursul):**

| Spunem copilului | În Scratch (EN) |
|------------------|-----------------|
| personaj | sprite |
| scenă / fundal | stage / backdrop |
| costum | costume |
| mesaj | broadcast |
| clonă | clone |
| steag verde | green flag |
| Sfârșitul jocului | Game Over (explicat o dată) |
| insignă | badge |
| depanare | debugging / bug hunt |

## Schelet obligatoriu (copiază la fiecare lecție nouă)

```markdown
# Lecția N — [Titlu concret: ce face copilul]
**Modulul X · [Nume modul]**  
**Code Kids Play · [Badge modul]**

> [1–2 fraze: ce facem azi + numele proiectului / fișierului]

---

## Obiectiv
[1 frază] La finalul orei știi / poți să…

## De ce contează
[1–2 fraze] Legat de ceva cunoscut (joc, desen, povești pe telefon…).

---

## Planul orei (120 minute)
| Minute | Ce facem |
|--------|----------|
| 0–10 | … |
| … | … |

---

## Pas cu pas
1. Din <span style="color:#…">Capitol</span> iei blocul <span style="color:#…">nume exact</span>
2. …
3. …

(Screenshot / GIF — opțional, când e gata materialul vizual)

---

## Încearcă tu
- [ ] Provocare mică, imediat după pași (1–3 minute de lucru)

---

## Greșeli frecvente
1. …
2. …

---

## De făcut azi — „[Nume proiect]”
Salvat: `Prenume_LX` (sau `Nume_MX_…`)

### Pasul 1 — …
- [ ] …

### Pasul 2 — …
- [ ] …

**Gata când:** …

---

## Bonus (dacă ai terminat mai devreme)
- [ ] …

## Recapitulare rapidă
1. …
2. …
3. …  
*(opțional: 2 întrebări tip quiz oral cu profesorul)*

## Temă
Opțional: …
```

---

## Mapare pe ora de 2h (clasă)

| Bloc template | Când în oră |
|---------------|-------------|
| Obiectiv + De ce contează | 0–5 min (cu vocea) |
| Pas cu pas + Încearcă tu | 5–25 min (încălzire) |
| De făcut azi | 25–100 min (proiect) |
| Greșeli frecvente | pe parcurs, când se blochează |
| Recap + Bonus + Temă | 100–120 min |

---

## Ce nu e în template (dar poate exista pe modul)

- Lecție **doar depanare** (ex. M4 L7) — păstrează scheletul, dar „Pas cu pas” = metoda de depanare
- Lecție **punte** (ex. M5 L1, M4 L10 Python) — Obiectiv = „deschizi ușa spre…”
- **Mini-proiect / prezentare / insignă** — tot pe schelet, cu checklist mai lung la „De făcut azi”
