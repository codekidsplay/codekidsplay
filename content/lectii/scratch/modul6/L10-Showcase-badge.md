## Pas cu pas

### 1) Polish A–F *(bifează ≥3 Minim)*
- [ ] **A** — Nume joc clar pe meniu  
- [ ] **B** — Sunete utile (sparge / craft / lovitură); se opresc la final  
- [ ] **C** — UI lizibil (inventar + HP + misiune)  
- [ ] **D** — Nimic „mort” (butoane false, clone rămase)  
- [ ] **E** — Controale pe scenă complete (clic / E / craft)  
- [ ] **F** — Victorie + Sfârșitul jocului clare, restart curat  

**Încearcă tu — polish (35–40 min)**  
- [ ] ≥3 bifă · steag ×2 ok  

### 2) Bug hunt scurt
Caută: minat fără rază · pune la 0 · HP spam · meniu fără reset · misiune deja câștigată.

**Încearcă tu (10 min)**  
- [ ] ≥1 bug notat și reparat **sau** „nu am găsit” semnat de coleg  

### 3) Prezentare 1–2 min
Pe foaie:
1. Titlu jocului  
2. „Tu faci …” (minezi / construiești / craftezi)  
3. „Greu a fost …”  
4. „Sunt mândru de …”  

Demo: Start → 30–40 s joc → misiune sau craft.

**Încearcă tu**  
- [ ] Ai prezentat · 1 feedback notat  

### 4) Insignă
- [ ] Ai parcurs Modulul 6 (sau recuperat cu profesorul)  
- [ ] Ai prezentat  
- [ ] Primești **Cube Crafter**

### 5) Complet
- [ ] ≥5 din A–F **sau** feature mică nouă **sau** feedback aplicat pe loc
