# Culori Scratch (denumiri în lecții)

Vrem **text colorat** (culoarea fontului), nu buline.

| Categorie | Culoare text | Exemplu |
|-----------|--------------|---------|
| Steag / start | `#3F8F2A` verde | steag verde, start |
| Mișcare | `#4C97FF` albastru | mergi, glisează |
| Aspect | `#9966FF` violet | spune, costum |
| Sunet | `#CF63CF` magenta | sunet |
| Control | `#FFAB19` portocaliu | așteaptă, repetă |
| Evenimente | `#E6A800` galben | Evenimente, click |
| Detectare | `#5CB1D1` cyan | atingere |
| Operatori | `#59C059` verde | + = < |
| Variabile | `#FF8C1A` portocaliu | scor |

### Cum vezi culorile în Cursor
1. Deschide lecția  
2. **Markdown: Open Preview to the Side** → `Cmd+Shift+V`  
3. **Nu** folosi toggle-ul „Preview | Markdown” inline (acolo HTML-ul colorat deseori nu apare)

În fișiere: `<span style="color:#3F8F2A;font-weight:700">start</span>`
