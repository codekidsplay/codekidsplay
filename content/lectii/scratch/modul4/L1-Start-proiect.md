## Ideea principală
L2–L5 / L8 / L9 = **proiecte grele separate** (alte fișiere).  
**Proiectul tău** (L1→L6→L7) = nivel **Creator**: nivele sau multiplayer + unelte din M2–M3.

### Strategie pe foaie (~10–12 min)
- [ ] Titlu + tip (joc / labirint / quiz / poveste cu alegeri / animație-joc)  
- [ ] **Mecanica principală** (1 frază)  
- [ ] Direcție wow: **nivele** sau **multiplayer local** (2 pe aceeași tastatură)  
- [ ] „E gata la L6 când…” (3 bifă tari)  
- [ ] **Azi (L1) trebuie să meargă:** motorul + primul pas wow

## Proiect de finalizat AZI — „Motorul”
Fișier: `Nume_M4_ProiectFinal`

### Obligatoriu pentru TOȚI
- [ ] Steag verde = **restart curat** (poziții / scor / scene la start)  
- [ ] Cel puțin **2 sprite-uri** care interacționează (sau 1 sprite + scenă cu logică)  
- [ ] Cel puțin **1 variabilă** pe scenă **sau** **1 mesaj (broadcast)** folosit pe bune  
- [ ] Cel puțin **1 decizie** (`dacă` / atingere / tastă)  
- [ ] Poți explica motorul în 20 secunde  

### Alege AZI o direcție „wow” (început — o termini la L6)
Bifează **una** și fă **primul pas** care rulează:
- [ ] **Mai multe nivele** — există Level 1 pe scenă + mesaj/buton „Level 2” (chiar dacă L2 e aproape gol)  
- [ ] **Multiplayer local** — 2 controale diferite pe aceeași tastatură (ex. săgeți vs WASD), ambii pe scenă  

### Minim pe tip (L1 — greu)
| Tip | Motorul AZI (trebuie toate) |
|-----|-----------------------------|
| **Joc / labirint** | Control erou + coliziune cu obstacol/zid + obiectiv vizibil (+ start pe direcția nivele **sau** 2 jucători) |
| **Quiz** | `scor` pe scenă + **2** întrebări + feedback (+ poți pregăti „runde” = nivele de greu) |
| **Poveste cu alegeri** | ≥2 scene + dialog + **1 alegere** pe căi diferite |
| **Animație-joc** | Sunet+mișcare + un input care schimbă scena (+ opțional 2 „acte” = nivele) |

### Bonus
Clone · timer · meniu Start · vieți

**Nu e suficient:** doar „merge cu săgețile pe fundal”.  
**E suficient:** logica de mai sus **rulează** + ai început nivele **sau** multiplayer.

## Bonus / Provocare (dacă ai terminat)
- [ ] Meniu Start (buton) deja din L1  
- [ ] Ai început **și** nivele **și** schiță multiplayer (nu e obligatoriu ambele la L6)  
- [ ] Variabilă `nivel` sau `jucator` pe scenă

## Temă
Opțional 15 min pe motor. Mâine L2 = **poveste cu alegeri** (fișier separat, tot greu).
