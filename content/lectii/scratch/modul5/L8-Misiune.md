# LECȚIA 8 — Misiune / obiectiv
**Modulul 5 · Lume de cuburi · Cam 2 ore**  
**Code Kids Play**

> La final: jocul are un **scop** — nu doar „umblu și sparg”.

---

## Planul orei (120 minute)

| Minute | Ce facem |
|--------|----------|
| 0–15 | Alege misiunea (una) |
| 15–30 | Criteriu de victorie pe foaie |
| 30–100 | Implementare + UI misiune |
| 100–115 | Playtest: se poate câștiga? |
| 115–120 | Temă |

---

## Ideea principală
Alege **una**:
1. Construiește un adăpost de N blocuri  
2. Găsește / craftează obiectul X și du-l la portal  
3. Supraviețuiește T secunde în Zona B  
4. Sparge N blocuri de tip rar  

Pe ecran: text „Misiune: …” + progres.

## Proiect de finalizat AZI
- [ ] Misiune afișată pe scenă  
- [ ] Progres vizibil (ex. 2/5)  
- [ ] Victorie clară (mesaj + stop sau scenă finală)  
- [ ] Încă poți pierde (vieți)  
- [ ] Restart resetează misiunea  

**Gata când:** un coleg înțelege misiunea din UI și o termină.

## Bonus / Provocare (dacă ai terminat)
- [ ] **2 misiuni** (principală + secundară) cu recompense diferite  
- [ ] Limită de timp pe misiune  
- [ ] Final secret dacă termini cu toate viețile intacte

## Temă
Nimic greu — salvează.
