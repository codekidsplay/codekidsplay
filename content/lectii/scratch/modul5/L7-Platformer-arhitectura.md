# Lecția 7 — Proiect mare: arhitectură și design
**Modulul 5 · Mecanici de joc · Block 3 · Fir L7→L10**  
**Code Kids Play · Maestru de jocuri**

> Azi începe **proiectul mare** (platformer / aventură scurtă): schiță + schelet Minim.  
> Fișier: `Prenume_Nume_M5_Proiect` (același până la L10)  
> **Regula minutului 50:** până atunci — **fără** decoruri complexe / costume noi; doar arhitectura.

---

## Obiectiv
**Minimum:** foaie cu design (erou · greu · win) · pe scenă: control + **gravitație/săritură** (din L1) · ≥1 nivel / traseu jucabil început · reset la steag.  
**Complet:** Minim + schiță inventar/monede pe scenă **sau** scroll început **sau** meniu Start schițat.

## De ce contează
L1–L6 = piese. L7 = **alegi** ce piese intră în produsul pe care îl prezinți la L10.

---

## Planul orei (120 minute)

| Minute | Ce facem |
|--------|----------|
| 0–15 | Ce e proiectul mare + regula min 50 |
| 15–35 | Schiță pe foaie (obligatoriu) |
| 35–50 | **Doar** schelet Minim — zero decor fancy |
| 50–100 | Complet: a doua mecanică + puțin polish vizual |
| 100–120 | Demo + 3 note pentru L8 |

---

## Pas cu pas

### 1) Schiță pe foaie *(obligatoriu)*
1. Titlu jocului  
2. Vedere: lateral (platformer) recomandat  
3. „Câștigi dacă…” / „Pierzi dacă…”  
4. Ce iei din L1–L6: bifează **≥2** (gravitație, scroll, inamic, listă, shop…)  
5. Hartă scurtă (start → mijloc → obiectiv)

**Încearcă tu (15–20 min)**  
- [ ] Foaia e completă înainte de Scratch  

### 2) Schelet Minim *(până la min ~50)*
1. `Prenume_Nume_M5_Proiect`  
2. Erou: x + `viteza_y` / săritură pe sol  
3. ≥2 platforme  
4. Steag = reset poziție + viteza_y  
5. **Nu** te bloca pe fundaluri frumoase

**Încearcă tu (20–25 min)**  
- [ ] Poți sări pe traseul scurt  
- [ ] Steag curat  

### 3) Complet (după min 50)
Alege **cel puțin una**:  
- [ ] Monede sau item pe scenă  
- [ ] Început de scroll pe X  
- [ ] Buton Start (chiar fără meniu full)  

### 4) Note pentru L8
Pe foaie: 3 lucruri de adăugat (inamici / clone / colectabile).

---

## Greșeli frecvente
1. **Decor înainte de fizică** — încalci regula 50.  
2. **Proiect nou la fiecare oră** — L7–L10 = același fișier.  
3. **Zero foaie** — te blochezi la L8.  
4. **Toate mecanicile L1–L6 odată** — alege 2–3.  
5. **Fără win pe foaie** — L9 nu știe ce să închidă.
