# LECȚIA 9 — Meniu Start + instructiuni
**Modulul 5 · Lume de cuburi · Cam 2 ore**  
**Code Kids Play**

> La final: jocul arată ca un **produs** — meniu, controale pe ecran, restart curat.

---

## Planul orei (120 minute)

| Minute | Ce facem |
|--------|----------|
| 0–10 | Checklist „arată a joc” |
| 10–70 | Meniu Start + ecran controale |
| 70–100 | Reset total la Start / steag |
| 100–115 | Test coleg fără explicații orale |
| 115–120 | Pregătire showcase L10 |

---

## Ideea principală
Buton **Start** → începe lumea.  
Ecran scurt: taste (mișcare, sparge, pune, craft).  
Steag verde / Start = inventar, vieți, zonă, misiune la valori inițiale.

## Proiect de finalizat AZI
- [ ] Meniu / buton Start  
- [ ] Controale vizibile (scenă sau „spune” la start)  
- [ ] Reset complet  
- [ ] Misiune + pericol + inventar încă merg  
- [ ] Un coleg joacă 5 min **fără** ajutorul tău  

**Gata când:** trece testul colegului.

## Bonus / Provocare (dacă ai terminat)
- [ ] Ecran **Pauză** (P) — oprește mobii / jocul  
- [ ] Buton **Cum se joacă** separat de Start  
- [ ] Dificultate: Ușor / Greu (vieți 5 vs 2) la meniu

## Temă
20 secunde: „În jocul meu tu …” (pentru L10).
