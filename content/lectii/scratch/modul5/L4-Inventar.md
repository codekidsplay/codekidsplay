# LECȚIA 4 — Inventar (1–3 tipuri)
**Modulul 5 · Lume de cuburi · Cam 2 ore**  
**Code Kids Play**

> La final: ai **inventar pe ecran** — ce ai strâns și ce poți pune.

---

## Planul orei (120 minute)

| Minute | Ce facem |
|--------|----------|
| 0–15 | Inventar = cutii cu numere |
| 15–35 | Variabile: `lemn`, `piatra`, `pamant` (max 3 tipuri) |
| 35–100 | Sparge → +1 în inventar; pune → −1 |
| 100–115 | UI pe scenă (vizibil) |
| 115–120 | Temă |

---

## Ideea principală
Nu pui infinit.  
Spargi iarbă → `pamant + 1`. Pui bloc → `pamant − 1` (dacă ai ≥1).  
Taste **1 / 2 / 3** = selectezi tipul activ (opțional dar recomandat).

## Proiect de finalizat AZI
- [ ] ≥**2 tipuri** în inventar (ideal 3)  
- [ ] Numerele se văd pe scenă  
- [ ] Sparge crește inventarul  
- [ ] Pune scade inventarul; **nu** pui dacă e 0  
- [ ] Steag verde resetează inventarul (sau la valori de start)  

**Gata când:** un coleg înțelege din UI ce resurse ai, fără să îi explici.

## Bonus / Provocare (dacă ai terminat)
- [ ] Selectare tip cu **1 / 2 / 3** + indicator pe ecran („activ: piatră”)  
- [ ] Cap inventar (ex. max 20 / tip)  
- [ ] „Stack” rar: spargi 1 bloc special → +3 resurse

## Temă
Selectare tip cu taste 1/2/3 (dacă lipsește).
