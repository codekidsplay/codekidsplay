# Lecția 10 — Completare + recap (labirint)
**Modulul 2 · Logică**  
**Code Kids Play · Logic Explorer**

> Azi **termini** labirintul (completare pe L9), îl **arăți** clasei și primești insigna **Logic Explorer**.  
> Fișier: `Prenume_Nume_L9` *(sau `Prenume_Nume_L10` = copie, ca să nu strici versiunea veche)*  
> Exemple: `Ana_Pop_L9` · `Ana_Pop_L10`

---

## Obiectiv
La finalul orei ai îmbunătățit labirintul, l-ai prezentat, și ai închis Modulul 2.  
**Minimum:** **1** îmbunătățire din A–F + restart curat + prezentare → **e suficient pentru insignă**.  
**Ținta orei (Complet):** **2** îmbunătățiri din A–F + prezentare + salvare.

## De ce contează
Ca la M1: proiectele bune se **refac** o dată, apoi se arată.  
Insigna **Logic Explorer** = logica (dacă, detectare, variabile, mesaje) e la activ — urmează **Modulul 3: Jocuri**.

---

## Planul orei (120 minute)

| Minute | Ce facem |
|--------|----------|
| 0–10 | Obiectiv + **Minim vs Complet** + reguli prezentare |
| 10–25 | Pas cu pas: lista A–F + checkpoint-uri (**Încearcă tu**) |
| 25–55 | **Completare** pe labirint (lucru individual) |
| 55–75 | Prezentări (~1–2 min × max. **10** elevi) |
| 75–120 | Quiz recap + **insignă** + ce urmează în M3 (+ Bonus dacă e timp) |

*(Repere profesor: la ~40 min fiecare copil are **cel puțin 1** îmbunătățire lipită și testată — checkpoint Minim; la ~55 min — gata de steag curat pentru prezentare, indiferent dacă e Minim sau Complet.)*

*(Grupa ≤10: prezentările nu umplu ora — nucleul e **completarea L9**. Dacă prezentările se termină la ~70 min → Bonus / quiz mai din timp.)*

## Pas cu pas

### 1) Idei de upgrade (alege din A–F)
Nu refaci de la zero. Deschizi „Labirintul meu” și **adaugi**.

| Literă | Upgrade |
|--------|---------|
| A | Monedă / stea: `scor +1` |
| B | Capcană: `vieti −1` |
| C | Mesaj `victorie` → schimbă fundalul (broadcast) |
| D | Buton „Joacă din nou” |
| E | Al 2-lea nivel (alt fundal) |
| F | Obstacol mobil (stânga–dreapta) |

*(**Minim** = **1** literă testată. **Complet** = **2** litere. Nu începe a doua până prima nu rulează pe steag.)*

**Încearcă tu — alegi ce adaugi (1–2 min)**  
- [ ] Ai ales **1** literă pentru Minim (ex. A)  
- [ ] Ai ales și o **a 2-a** țintă pentru Complet (ex. F) — o faci **după** ce prima e gata  
- [ ] Știi: la min 55 prezinți **oricum** — cu 1 e suficient pentru insignă  

### 2) Restart curat + prima îmbunătățire
1. Înainte să adaugi: verifică steagul — reset **complet**:  
   loc start → efecte anulate → sunete oprite → scor/vieți la 0 / 3 (dacă există)  
2. Lipesti **1** upgrade din listă  
3. Steag de **două** ori — labirintul încă se poate termina  

**Încearcă tu — 1 îmbunătățire gata și testată (mijlocul intervalului, ~min 40)**  
*(Checkpoint Minim — nu începe a doua până aici.)*

- [ ] **1** din A–F e **lipită** și rulează pe steag  
- [ ] Steag de două ori → restart curat (fără haos)  
- [ ] Labirintul încă se poate termina  
- [ ] Salvat: `Prenume_Nume_L9` (sau `Prenume_Nume_L10`)  
- [ ] Abia acum, dacă mai e timp: începi a **2-a** îmbunătățire  

### 3) Prezentare (1–2 min)
1. „Eroul meu e…”  
2. „Dacă ating peretele…”  
3. „Azi am adăugat…” (**un** lucru — sau cele 2, dacă ai Complet)  
4. Steag → demo scurt  
5. Clasa: aplauze + 1 compliment; tu: „Mulțumesc”

**Încearcă tu — proba de prezentare (2 min, cu un coleg)**  
- [ ] Poți spune: cine e + reguli + ce ai adăugat azi  
- [ ] Steagul rulează curat o dată  

### 4) Recap Modul 2 (cu profesorul, pe scurt)

| Idee | Unde |
|------|------|
| `dacă` / `dacă … altfel` | L1–L2 |
| Detectare (culoare, personaj, margine) | L3 |
| Taste + forever | L4, L7 |
| Variabile + operatori | L5–L6 |
| Stop / mesaje | L7–L8 |

### 5) Ce urmează (Modulul 3) — 2–3 minute
M2 = logică și labirint.  
M3 = **jocuri** (scor, nivele, clone…).

### 6) Insigna (convenție CKP)
1. Ai **Minim** (1 îmbunătățire + restart curat) + **prezentat** + proiect **salvat** → **insignă**  
2. Profesorul: „Ai insigna **Logic Explorer**”  
3. Opțional: sticker / cartonaș / diplomă  
4. Recunoaștere în clasă — nu notă, nu cont obligatoriu  

*(Complet = 2 îmbunătățiri: ținta orei, nu pragul pentru insignă.)*  
*(Aceeași convenție: Scratch Starter → Logic Explorer → Game Builder…)*

## Greșeli frecvente
1. **Upgrade care strică controlul** — viteză prea mare după obstacol mobil; coboară viteza.  
2. **Prezentare fără steag curat** — resetează înainte (loc / scor / sunete).  
3. **Două upgrade-uri netestate** — la min 55 e stricat; fă **1 → testează → apoi 2**.  
4. **„N-am 2, deci n-am reușit”** — **1** + prezentare = Minim = **insignă**.  
5. **Quiz sărit** — măcar 3 întrebări dacă e puțin timp.  
6. **Nume fișier** — `Prenume_Nume_L9` / `Prenume_Nume_L10`, nu doar `Ana_L9`.
