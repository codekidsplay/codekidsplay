## Pas cu pas

### 1) Idei de upgrade (alege **≥2**)
| Literă | Upgrade |
|--------|---------|
| A | Monedă / stea: `scor +1` |
| B | Capcană: `vieti −1` |
| C | Mesaj `victorie` → schimbă fundalul (broadcast) |
| D | Buton „Joacă din nou” |
| E | Al 2-lea nivel (alt fundal) |
| F | Obstacol mobil (stânga–dreapta) |

### 2) Prezentare (1–2 min)
1. „Eroul meu e…”  
2. „Dacă ating peretele…”  
3. „Azi am adăugat…” (cele 2 upgrade-uri)  
4. Steag → demo scurt  

### 3) Restart curat
Înainte de prezentare: verifică steagul (scor/vieți/poziții/sunete).

1. **Upgrade care strică controlul** — viteză prea mare după obstacol mobil; coboară viteza.

4. **Quiz sărit** — măcar 3 întrebări dacă e puțin timp.
