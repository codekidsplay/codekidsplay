# LECȚIA 3 — Detectare: atingere
**Modulul 2 · Logică · Cam 2 ore**  
**Code Kids Play**

> La final știi: Scratch poate „simți” dacă personajul atinge o culoare, alt personaj sau marginea.

---

## Planul orei (120 minute)

| Minute | Ce facem |
|--------|----------|
| 0–10 | Recap |
| 10–30 | Ce poate „simți” personajul |
| 30–55 | Atinge culoarea / personajul / marginea |
| 55–85 | Exerciții pe scenă |
| 85–110 | Mini-proiect: „Nu călca pe lavă” |

---

## Ideea principală
Blocuri utile (categoria **Detectare**):
- **atinge culoarea …?**  
- **atinge personajul …?**  
- **atinge marginea?**  

Le pui în **dacă … atunci**.

Sfat: culoarea de pe scenă trebuie să fie clară (ex. roșu = pericol).

## Exerciții
1. Dacă atinge marginea → întoarce + sunet  
2. Dacă atinge un personaj „monedă” → spune „Yaay!”  
3. Dacă atinge culoarea roșie → du-te la start (x:0 y:0)

## Mini-proiect: „Nu călca pe lavă”
- Fundal cu o zonă colorată (= lavă)  
- Miști personajul cu tastele  
- Dacă atinge lava → înapoi la start + mesaj „Ai călcat!”

## Bonus / Provocare (dacă ai terminat)
- [ ] Detectezi **culoare** și **sprite** în același proiect  
- [ ] Zonă periculoasă + zonă bonus (efecte opuse)  
- [ ] La atingere: scurtă **imunitate** (așteaptă) ca să nu spam-uiască mesajul

## Temă
Adaugă o zonă „sigură” (altă culoare): dacă o atingi → spune „Ok!”.
