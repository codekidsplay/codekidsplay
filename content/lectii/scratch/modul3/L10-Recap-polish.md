# Lecția 10 — Finisări, prezentare și insignă
**Modulul 3 · Jocuri**  
**Code Maker Club · Game Builder**

> Azi **termini** jocul din L9, îl **îmbunătățești**, îl **arăți** clasei și primești insigna **Game Builder**.  
> Fișier: `Prenume_Nume_M3_L9` *(sau `Prenume_Nume_M3_L10` = copie, ca să nu strici versiunea veche)*  
> Exemple: `Ana_Pop_M3_L9` · `Ana_Pop_M3_L10`

---

## Obiectiv
La finalul orei ai îmbunătățit jocul „Prinde obiectele”, l-ai prezentat clasei și ai închis Modulul 3.  
**Minim:** **1** îmbunătățire din A–F + restart curat + prezentare → **e suficient pentru insignă**.  
**Ținta orei (Complet):** **2** îmbunătățiri din A–F + prezentare + salvare.

## De ce contează
Ca la finalul M1 și M2: proiectele bune se **refac** o dată, apoi se arată.  
Insigna **Game Builder** = știi să pui împreună control, clone, scor, vieți/timer și meniu într-un joc care se termină — urmează **Modulul 4**.

---

## Planul orei (120 minute)

| Minute | Ce facem |
|--------|----------|
| 0–10 | Obiectiv + Minim vs Complet + **harta M3** |
| 10–25 | Alegi din A–F *(sigur vs avansat)* + mini-verificări |
| 25–55 | **Finisări** pe joc (lucru individual) |
| **55** | **Stop cod** → salvezi → **Ecran mare** — încep prezentările |
| 55–75 | Prezentări (~1–2 min × max. **10** elevi) |
| 75–120 | Quiz recap + **insignă** + ce urmează în M4 (+ Bonus dacă e timp) |

*(La ~40 min: fiecare are **cel puțin 1** upgrade testat. La **55**: gata de prezentare **oricum** — cu 1 e suficient pentru insignă.)*

---

## Pas cu pas

### 1) Idei de upgrade (A–F) — alege inteligent
Nu refaci de la zero. Deschizi „Prinde obiectele” și **adaugi**.

| Literă | Upgrade | Nivel |
|--------|---------|--------|
| **C** | Sunet / efect la prindere sau Game Over | **Sigur** (~2–3 min) |
| **F** | Instrucțiuni pe meniu *(„Folosește săgețile…”) * | **Sigur** |
| **B** | Meniu Start cu titlu propriu, dacă lipsește (L8) | Mediu |
| **A** | Nivel 2: fundal + țintă de scor mai mare (L6) | Mediu |
| **D** | Clonă „rea” (bombă) care scade viață (L7) | **Avansat** |
| **E** | High score pe scenă (nu se resetează la Start) | **Avansat** |

**Ghid (min 10–25):**  
- Vrei **Minim garantat** → alege **C** sau **F** întâi.  
- Ai terminat C/F și mai e timp → **A** sau **B**.  
- Ești rapid → **D** sau **E** (ca a 2-a literă, după ce prima rulează).  

*(**Minim** = **1** literă testată. **Complet** = **2**. Nu începe a doua până prima nu rulează pe steag.)*

**Încearcă tu — alegi ce adaugi (1–2 min)**  
- [ ] Ai ales **1** literă pentru Minim (ex. **C** sau **F**)  
- [ ] Opțional: o **a 2-a** țintă pentru Complet — **după** ce prima e gata  
- [ ] Știi: la min **55** prezinți **oricum**  

### 2) Restart curat + prima îmbunătățire
1. Înainte să adaugi: steag → reset **complet** (loc, efecte, sunete, scor/vieți/timp, meniu)  
2. Lipești **1** upgrade  
3. Steag de **două** ori — jocul încă se poate termina  

**Încearcă tu — 1 îmbunătățire gata (~min 40)**  
- [ ] **1** din A–F e lipită și rulează  
- [ ] Steag de două ori → restart curat  
- [ ] Jocul se poate termina (victorie / Game Over)  
- [ ] Salvat  
- [ ] Abia acum, dacă e timp: a **2-a** literă  

### 3) Minutul 55 — Stop Cod, Deschide Scena
1. **Salvezi** proiectul  
2. Trec în **Ecran mare** (full screen) pe Scratch  
3. **Stop** la scrierea de cod nou — chiar dacă ai doar **1** upgrade  
4. Ești mândru: ai un joc **de la Meniu la final**, jucabil  

**Încearcă tu — gata de scenă (1 min)**  
- [ ] Salvat · ecran mare · știi ce spui în 1–2 min  

### 4) Prezentare (1–2 min) — script

**Cum prezinți jocul tău:**  
1. „Salut! Jocul meu se numește **[titlu]**.”  
2. „Regula e simplă: controlezi **[eroul]** și prinzi **[obiectul]**.”  
3. „Azi am adăugat: **[litera A–F]** — ex. sunete / nivel 2 /…”  
4. **Demo:** steag → Start → joci câteva secunde  
5. „Mulțumesc!”  

Clasa: aplauze + 1 compliment.

**Încearcă tu — proba cu un coleg (2 min)**  
- [ ] Poți spune titlul + regula + ce ai adăugat  
- [ ] Steagul rulează curat o dată  

### 5) Harta Modulului 3

| | Ce ai învățat |
|--|----------------|
| ✔ L1–L2 | Control + atingeri |
| ✔ L3–L5 | Scor, vieți & timer (finale) |
| ✔ L6 | Nivele & fundal |
| ✔ L7 | Clone |
| ✔ L8 | Meniu Start (mesaje) |
| ✔ L9 | Jocul „Prinde obiectele” |
| ★ L10 | Finisări, prezentare & **insignă Game Builder** |

### 6) Ce urmează (Modulul 4) — 2–3 minute
M3 = jocuri. M4 = pasul următor pe modulele Code Maker Club.

### 7) Insigna (convenție CKP)
1. **Minim** (1 upgrade + restart curat) + **prezentat** + **salvat** → **insignă**  
2. Profesorul: „Ai insigna **Game Builder**”  
3. Opțional: sticker / cartonaș / diplomă  

*(Complet = 2 upgrade-uri: ținta orei, nu pragul pentru insignă.)*

---

## Greșeli frecvente
1. **Începi cu D sau E** și rămâi fără Minim — fă întâi **C** sau **F**.  
2. **Upgrade care strică jocul** — testează pe steag înainte de a doua literă.  
3. **La min 55 încă scrii cod** — salvezi, ecran mare, prezinți cu ce ai.  
4. **„N-am 2, deci n-am reușit”** — **1** + prezentare = Minim = **insignă**.  
5. **Prezentare fără steag curat** — resetează înainte.  
6. **Nume fișier** — `Prenume_Nume_M3_L9` / `M3_L10`, nu doar `Ana_M3_L9`.

## De făcut azi — Finisări + prezentare + insignă
Salvat: `Prenume_Nume_M3_L9` și/sau `Prenume_Nume_M3_L10`

### Minim vs Complet

| | Ce trebuie |
|--|------------|
| **Minim („am reușit” + insignă)** | **1** din A–F + restart curat + **prezentare** + salvare |
| **Complet (ținta orei)** | Minim + a **2-a** din A–F |

Dacă rămâi în urmă: **prezinți cu o îmbunătățire — e suficient pentru insignă.**  
La min **55**: Stop Cod → ecran mare → prezentări **oricum**.

- [ ] Ai prezentat · ai dat / primit un compliment

- [ ] Salvat · quiz · insigna **Game Builder**

## Schema pe scurt *(pe foaie)*

**Prezentare (1–2 min):**  
1. Titlul jocului  
2. Regula (erou + obiect)  
3. Ce am adăugat (litera A–F)  
4. Demo: steag → Start → joacă puțin  
5. Mulțumesc  

**Harta M3:** L1–L2 control/atingeri · L3–L5 scor/vieți/timer · L6 nivele · L7 clone · L8 meniu · L9 joc · ★ L10 finisări + insignă
