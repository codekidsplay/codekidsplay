## Polish — termină AZI
Alege **cel puțin 3**:
- [ ] Viteză ok  
- [ ] Sunete clare  
- [ ] Scor / vieți vizibile  
- [ ] Start clar  
- [ ] Victorie / Game Over clare  
- [ ] Nume proiect ok  

## Quiz rapid
1. Ce e feedback-ul?  
2. Ce face o clonă?  
3. De ce avem Start?  
4. Cum treci la nivelul 2?  
5. Ce faci la 0 vieți?

## Punte Modul 4
Alegi tu un proiect mai mare (poveste, quiz, animație, joc) și îl duci pe module.
