# LECȚIA 4 — Proiect: „3 vieți” (Game Over)
**Modulul 3 · Jocuri · Cam 2 ore**  
**Code Kids Play**

> La finalul orei ai un joc cu **3 vieți**: atingi pericolul → −1; la 0 → Game Over.

---

## Planul orei (120 minute)

| Minute | Ce facem |
|--------|----------|
| 0–10 | Recap scor |
| 10–30 | Variabila `vieti` |
| 30–95 | Proiect complet |
| 95–110 | Test: pierzi o rundă corect |
| 110–120 | Temă |

---

## Ideea principală
La start: 3 vieți. Pericol → −1. La 0 → „Game Over”.  
După lovitură: **așteaptă 0.5–1s** ca să nu scadă viețile de 10 ori.

## Proiect de finalizat AZI — „Supraviețuiește”
1. `vieti` pe scenă = 3 la start  
2. 1–2 obstacole care se mișcă sau stau  
3. Atingi obstacol → vieti −1 + „Au!”  
4. Dacă vieti = 0 → „Game Over” + stop all  
5. Opțional: o stea care dă +1 la scor (fără să fie obligatoriu să câștigi pe scor)

**Gata când:** poți pierde clar și poți reporni cu steagul verde.

## Bonus / Provocare (dacă ai terminat)
- [ ] La 1 viață: fundal/efect „pericol”  
- [ ] Inimă pe hartă care dă **+1 viață** (o singură dată)  
- [ ] Game Over cu buton „Încearcă din nou” (nu doar steag)

## Temă
Încearcă cu 5 vieți. Ce e mai ok?
