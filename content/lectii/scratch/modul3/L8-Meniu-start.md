# LECȚIA 8 — Proiect: „Apasă Start”
**Modulul 3 · Jocuri · Cam 2 ore**  
**Code Kids Play**

> La finalul orei ai un joc cu **meniu**: nu începe până apeși butonul Start.

---

## Planul orei (120 minute)

| Minute | Ce facem |
|--------|----------|
| 0–10 | De ce meniu? |
| 10–30 | Buton + mesaj „start joc” |
| 30–95 | Proiect complet (meniu + joc scurt) |
| 95–110 | Test: Start → joacă → gata |
| 110–120 | Temă |

---

## Ideea principală
Steagul verde = arată meniul.  
Click pe **Start** = începe jocul (scor, control, clone).

## Proiect de finalizat AZI — „Meniu + mini-joc”
1. Titlu + buton START pe scenă  
2. Steag verde: arată meniul; ascunde eroul / oprește clonele  
3. Click Start → trimite „start joc” · ascunde butonul  
4. Când primesc „start joc”: eroul apare + se mișcă; (opțional) pornesc monedele  
5. La victorie sau Game Over: mesaj clar  
6. Opțional: buton „Din nou”  

Poți refolosi „Ploaie de monede” sau „Prinde 5” — important e meniul.

**Gata când:** fără Start, jocul nu „fugă” singur.

## Bonus / Provocare (dacă ai terminat)
- [ ] Meniu cu **2 butoane**: Start + Cum se joacă  
- [ ] La Start: reset scor, vieți, nivel, poziții  
- [ ] Ecran titlu cu numele jocului tău

## Temă
Desenează un costum frumos pentru buton.
