## Criterii — proiect gata AZI
- [ ] Buton **Start**  
- [ ] Erou stânga/dreapta  
- [ ] Obiecte care cad (clone)  
- [ ] Prins → scor +1  
- [ ] Ratat jos **sau** obstacol → vieți −1 (alege una)  
- [ ] Victorie la scor țintă **sau** Game Over la 0 vieți  
- [ ] Steag verde / Start = curat  

Nume: `Nume_M3_PrindeObiectele`

## Ordine rapidă
1. Meniu Start  
2. Erou  
3. Clone  
4. Scor  
5. Vieți sau timer  
6. Final (mesaj + stop)  

## Bonus / Provocare (dacă ai terminat)
- [ ] **2 nivele** în catcher (țintă scor mai mare pe L2)  
- [ ] Power-up rar (încetinește obiectele 5 sec)  
- [ ] High score pe scenă (variabilă care nu se resetează la Start — doar la steag)

## Temă
Cam 15 min polish acasă, dacă vrei — mâine prezentăm.
