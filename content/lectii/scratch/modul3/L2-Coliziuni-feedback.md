# LECȚIA 2 — Proiect: „Au!” și „Yaay!” (feedback)
**Modulul 3 · Jocuri · Cam 2 ore**  
**Code Kids Play**

> La finalul orei ai un joc mic: atingi steaua → bravo; atingi obstacolul → „Au!” + sunet.

---

## Planul orei (120 minute)

| Minute | Ce facem |
|--------|----------|
| 0–10 | Recap L1 |
| 10–30 | Ce e feedback? |
| 30–95 | Proiect complet |
| 95–110 | Test + prezentare scurtă |
| 110–120 | Temă |

---

## Ideea principală
Când eroul **atinge** ceva, jocul răspunde (sunet, mesaj, costum).

## Proiect de finalizat AZI — „Stea sau pericol”
1. Erou cu taste  
2. Stea: dacă o atingi → sunet frumos + spune „Yaay!” + steaua se ascunde  
3. Obstacol: dacă îl atingi → sunet + spune „Au!” 0.5s + (opțional) costum scurt „lovit”  
4. Steag verde: steaua reapare, eroul la start  

**Gata când:** ambele reacții merg dintr-o rulare.

## Bonus / Provocare (dacă ai terminat)
- [ ] Feedback diferit: **sunet + costum + spune** la aceeași coliziune  
- [ ] 2 tipuri de atingere (bonus vs obstacol) cu reacții opuse  
- [ ] Scurtă imunitate 0.5s după „Au!” ca să nu spam-uiască

## Temă
Schimbă sunetele.
