# LECȚIA 1 — Design + proiect: „Jocul meu pe hârtie și pe scenă”
**Modulul 3 · Jocuri · Cam 2 ore**  
**Code Kids Play · Game Builder**

> La finalul orei ai: o foaie cu regulile jocului **și** scena Scratch cu erou + obstacol + țintă, gata de salvat.

---

## Planul orei (120 minute)

| Minute | Ce facem |
|--------|----------|
| 0–10 | Ce e un joc? |
| 10–35 | Pe hârtie: erou, obstacol, obiectiv |
| 35–90 | În Scratch: scenă + 3 personaje + start |
| 90–110 | Rulează + arată pe rând |
| 110–120 | Temă scurtă |

---

## Ideea principală
Un joc are: **erou**, **obstacol**, **obiectiv** (cum câștigi).

## Proiect de finalizat AZI
1. Pe foaie: nume joc + 3 rânduri (erou / obstacol / cum câștigi)  
2. În Scratch: fundal + erou + obstacol + țintă (stea/ieșire)  
3. Steag verde: toți la poziția de start  
4. Eroul se mișcă cu tastele (stânga/dreapta sau săgeți)  

**Gata când:** salvezi `Nume_M3_L1_Design` și poți mișca eroul pe scenă.

## Bonus / Provocare (dacă ai terminat)
- [ ] Pe foaie: **tabel** erou / obstacol / obiectiv / controale  
- [ ] În Scratch: obstacol care se mișcă deja (chiar mic)  
- [ ] Titlu pe scenă (sprite text sau spune la start)

## Temă (opțional, 10 min)
Schimbă un costum la erou.
