# LECȚIA 4 — Pini: LED extern (sau buzzer)
**Modulul 2 · micro:bit (blocuri) · Cam 2 ore**  
**Code Kids Play**

> La final: un LED (sau buzzer) pe breadboard/crocodil se aprinde din cod.

Dacă nu aveți LED-uri: folosiți doar pinii + măsurătoare / simulați pe LED-ul matrix ca „pin virtual” + notați schema.

---

## Planul orei (120 minute)

| Minute | Ce facem |
|--------|----------|
| 0–20 | Pini 0,1,2,3V,GND — siguranță |
| 20–45 | Montaj simplu (profesor verifică) |
| 45–100 | digital write / analog (opțional) |
| 100–115 | Demo |
| 115–120 | Temă |

---

## Ideea principală
Nu scurtcircuita 3V cu GND. Profesorul validează circuitul.

## Proiect de finalizat AZI
- [ ] Circuit verificat
- [ ] LED extern ON/OFF din buton SAU senzor
- [ ] Funcționează și pe placă, nu doar simulator
- [ ] Schema pe foaie (simplă)

**Gata când:** LED-ul extern reacționează la program.

## Bonus / Provocare (dacă ai terminat)
- [ ] 2 LED-uri pe pini diferiți
- [ ] Blink cu forever
- [ ] LED = semafor cu 3 stări

Desenează schema.
