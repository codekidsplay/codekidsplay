# LECȚIA 2 — Radio: două micro:bit vorbesc
**Modulul 2 · micro:bit (blocuri) · Cam 2 ore**  
**Code Kids Play**

> La final: placa A trimite, placa B primește (sau invers) — același grup radio.


---

## Planul orei (120 minute)

| Minute | Ce facem |
|--------|----------|
| 0–20 | Ce e radio pe micro:bit |
| 20–40 | radio set group + send / receive |
| 40–100 | Proiect: telecomandă icon (A trimite, B arată) |
| 100–115 | Test distanță în sală |
| 115–120 | Temă |

---

## Ideea principală
Același **group** = același „canal”. Fără group = haos în clasă.

## Proiect de finalizat AZI
- [ ] Group setat (ex. numărul echipei)
- [ ] Send la buton
- [ ] Receive afișează pe LED
- [ ] Funcționează pe 2 plăci reale

**Gata când:** mesajul ajunge pe a 2-a placă.

## Bonus / Provocare (dacă ai terminat)
- [ ] Trimite număr (scor)
- [ ] 3 mesaje diferite (A/B/A+B)
- [ ] LED pe emițător când trimite

## Temă
Notează group-ul echipei.
