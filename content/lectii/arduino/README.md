# Arduino — Curriculum Code Maker Club

**4 module × 10 lecții = 40 lecții**  
**Vârstă orientativă:** 10+ (cod C++ minim, citit și modificat; nu scris de la zero)  
**Durată oră CKP:** ~**2 ore** (Minim = 45–60 min; restul = Complet + prezentare)  
**Platformă:** **Tinkercad Circuits** (simulator Arduino Uno, gratuit, în browser) — fără kit obligatoriu  
**Pe placa reală (opțional):** fiecare lecție are o notă „Pe placa reală” pentru copiii care au kit

### Badge-uri

| Modul | Nume | Badge |
|-------|------|--------|
| 1 | Primele circuite | **Circuit Starter** |
| 2 | Senzori | **Sensor Scout** |
| 3 | Afișaj și mișcare | **Display Maker** |
| 4 | Proiecte complete | **Arduino Creator** |

### Ordine

```
Circuit Starter → Sensor Scout → Display Maker → Arduino Creator
```

### Format lecție (~120 min)

1. Warm-up / recap (10–15)  
2. Demo scurt (10–15)  
3. **Minim** — circuitul lecției, rulat în simulator (45–55)  
4. **Complet / Bonus** (25–35)  
5. Prezentare scurtă + salvare (10–15)  

Fiecare lecție se închide cu un **circuit funcțional salvat**.  
Salvare sugerată: `Prenume_Nume_A1_L01` … `A4_L10`.

### Reguli pentru conținut

- Lecții **originale**: proiectele, titlurile și scenariile nu copiază alte cursuri.  
- Componente doar din biblioteca **Tinkercad Circuits** (Arduino Uno, LED, RGB, buton, potențiometru, buzzer, fotorezistor, TMP36, ultrasonic HC-SR04, PIR, umiditate sol, tilt, LCD 16×2, 7 segmente, servo, motor DC, tastatură 4×4, NeoPixel, receptor IR).  
- Cod scurt, comentat; copiii modifică valori și linii, nu scriu programe lungi.  
- Fiecare lecție: **Obiectiv → Plan → Pas cu pas → Greșeli frecvente → De făcut → Schema pe scurt**.
