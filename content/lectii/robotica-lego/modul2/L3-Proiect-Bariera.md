# LECȚIA 3 — Proiect: Bariera / poarta automată
**Modulul 2 · Robotică LEGO WeDo 2.0 · Cam 2 ore**  
**Code Kids Play**

> La final ai o barieră care se ridică când detectează apropierea (sau la înclinare).


---

## Planul orei (120 minute)

| Minute | Ce facem |
|--------|----------|
| 0–15 | Idee: parcare / trecere |
| 15–100 | Build + senzor + motor |
| 100–115 | Simulare pe masă |
| 115–120 | Temă |

---

## Ideea principală
Clasic WeDo: senzor vede → motor deschide.

## Proiect de finalizat AZI
- [ ] Barieră vizibilă pe masă
- [ ] Deschide la senzor SAU comandă clară
- [ ] Se închide după timp / condiție
- [ ] Stabilă (nu cade)

**Gata când:** un coleg „trece” și bariera reacționează.

## Bonus / Provocare (dacă ai terminat)
- [ ] Semnal sunet înainte de închidere
- [ ] Două viteze de deschidere
- [ ] Decor: casetă / semafor LEGO

## Temă
Notează timpul de deschidere.
