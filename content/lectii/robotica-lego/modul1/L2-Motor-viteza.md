# LECȚIA 2 — Motor: viteză, timp, direcție
**Modulul 1 · Robotică LEGO WeDo 2.0 · Cam 2 ore**  
**Code Kids Play**

> La final controlezi motorul: înainte/înapoi, viteză, durată — pe un mini-vehicul sau suport.


---

## Planul orei (120 minute)

| Minute | Ce facem |
|--------|----------|
| 0–15 | Recap hub + motor |
| 15–40 | Blocuri: timp, putere, direcție |
| 40–100 | Construiești bază + test programe |
| 100–115 | Demo pe rând |
| 115–120 | Temă |

---

## Ideea principală
Motorul e „mușchiul”. Programul decide **cât**, **în ce sens**, **cât de tare**.

## Proiect de finalizat AZI
- [ ] Construcție stabilă cu motor montat
- [ ] Program A: merge 2s înainte
- [ ] Program B: înapoi 2s
- [ ] Program C: 3 viteze diferite pe rând
- [ ] Salvat pe dispozitiv / poză ecran

**Gata când:** poți arăta cele 3 programe fără să reconstruiesti.

## Bonus / Provocare (dacă ai terminat)
- [ ] Secvență: înainte → pauză → înapoi → stop
- [ ] Motor + sunet/LED hub (dacă e în app)
- [ ] Cronometrezi pe ceas: exact 3 secunde

## Temă
Pe foaie: ce viteză e mai sigură pentru un robot mic?
