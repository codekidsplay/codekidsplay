# LECȚIA 1 — Ce este WeDo 2.0?
**Modulul 1 · Robotică LEGO WeDo 2.0 · Cam 2 ore**  
**Code Kids Play · Robot Starter**

> La final știi piesele din cutie, pornești hub-ul și ai un motor care se învârte 2 secunde.


---

## Planul orei (120 minute)

| Minute | Ce facem |
|--------|----------|
| 0–20 | Ce e un robot? WeDo vs jucărie |
| 20–45 | Inventar cutie: hub, motor, senzori, piese |
| 45–70 | App WeDo 2.0 + conectare tabletă/PC |
| 70–105 | Primul program: motor ON 2s |
| 105–120 | Reguli atelier (4 cutii → echipe de 2) |

---

## Ideea principală
WeDo 2.0 = hub inteligent + **1 motor** + senzor **înclinare** + senzor **mișcare/distanță** + piese LEGO.
Atelier CKP: **4 cutii** → ideal **2 elevi / cutie**.

## Proiect de finalizat AZI
- [ ] Hub încărcat / pornit
- [ ] App deschisă, hub conectat
- [ ] Motor se învârte la Start (program salvat)
- [ ] Echipa știe cine construiește / cine programează (roluri)

**Gata când:** motorul rulează din app fără ajutor.

## Bonus / Provocare (dacă ai terminat)
- [ ] Schimbă viteza motorului (lent / rapid)
- [ ] Program: motor stânga 1s, dreapta 1s
- [ ] Desenează pe foaie hub + 3 piese pe care le-ai folosit

## Temă
Nu demontați tot — lăsați hub+motor pregătit pentru L2.
