# Python — Curs de programare (10+ ani)

4 module × 10 lecții, Python 3 cu Thonny. Fiecare lecție durează 2 ore și are 10 exemple, proiect și exerciții A–E.

| Modul | Titlu | Insigna |
|-------|-------|---------|
| 1 | Primii pași în Python | Python Starter |
| 2 | Repetăm, colecționăm, organizăm | Python Builder |
| 3 | Desenăm cu Turtle | Turtle Artist |
| 4 | Jocuri cu Pygame | Game Creator |

Pentru modulul 4 se instalează biblioteca Pygame (`pip install pygame`, din Thonny: *Tools → Manage packages*).
