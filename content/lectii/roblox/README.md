# Roblox Studio — Curriculum Code Kids Play

**Curs:** Roblox Studio (`c12`)  
**Public:** **12+ ani** (bandă site: Micii Programatori)  
**Formă:** **4 module × 10 lecții** · badge la finalul fiecărui modul  
**Limbaj scripting:** Luau (Roblox)  
**Proiect pe verticală:** același **Obby** crescut pe module (nu 4 jocuri noi de la zero)

*Premisă 12+:* ritm și vocabular ca la C++/Unity pe landing; M1 rămâne fără cod ca să nu amestecăm Studio + sintaxă în aceeași oră, dar din M2 putem cere Minim mai ferm (erori citite din Output, prefix `Srv_`/`Cli_`).

---

## Ideea de bază

| Modul | Badge | Ce înveți | Ce termini (capstone) |
|-------|--------|-----------|------------------------|
| **M1** | **Place Builder** | Studio + construcție (fără / cu cod minim) | **Lumea Obby** explorabilă (start → finish) |
| **M2** | **Script Starter** | Luau de bază + client vs server | **Mecanisme** pe aceeași lume (ușă / monedă / checkpoint) |
| **M3** | **Game Logic** | leaderstats, GUI, RemoteEvent (Minim) | **Obby jucabil** cu scor / checkpoint-uri |
| **M4** | **Roblox Creator** | DataStore Minim, ModuleScript, polish, publish | **Jocul publicat** + prezentare |

**Convenții CKP (ca Scratch):** Minim vs Complet · checkpoint-uri dese · L9 mini-proiect · L10 completare + prezentare + insignă  
**Nume fișiere Place:** `Prenume_Nume_M1` … (sau Place pe contul Roblox cu același tipar)  
**Scripturi:** prefix **`Srv_`** (Script pe server) / **`Cli_`** (LocalScript pe client) — din M2
