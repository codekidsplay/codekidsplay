## Obiectiv
La finalul orei **prezinți** jocul, ai trecut prin **lista finală** și (dacă e permis) jocul e **publicat**. Primești **insigna Roblox Creator**.  
**Minimum:** o **prezentare de 3 minute** (demo + un script explicat + o regulă de securitate) și jocul final salvat.  
**Ținta orei (Complet):** Minim + prezentare completă (5 puncte) + **publicare** conform regulilor (Privat sau Public, hotărât cu profesorul) + **reflecție** scrisă pe cele 4 module + plan pentru „ce urmează".

## De ce contează
A construi un joc e o pasiune; a-l **explica** altora e o abilitate. Programatorii și designerii prezintă constant ce au făcut. Prezentarea te ajută să înțelegi cu adevărat codul tău.

> **Despre publicare:** *dacă* publici, *unde* și *cum* (Privat/Public) se hotărăște cu **profesorul și părinții**. Fără acord, rămâi la **Privat** sau doar în Studio. Nu e nicio rușine.

## Pas cu pas

### 1) Lista finală
Înainte de orice, verifici din nou:
- [ ] Deschizi **`_FINAL`**  
- [ ] Output curat de la un capăt la altul  
- [ ] DataStore: numele **final** (nu de test)  
- [ ] Fără scripturi/valori de test  
- [ ] Nume, descriere, setări gata *(L8)*  
- [ ] Salvat

### 2) Publicarea *(dacă e permis)*
Pașii (profesorul îi arată, meniurile se pot schimba):
1. **Save**  
2. **Publish to Roblox** (permisiune: cea hotărâtă cu profesorul)  
3. Deschizi jocul din **Roblox Player**  
4. Joci de la început  
5. Verifici că **salvarea** merge (ieși, intri)

| Variantă | Când |
|----------|------|
| **Privat** | implicit; doar tu/profesorul |
| **Public** | doar cu **acordul** părinților și al profesorului |
| **Nu publici** | e perfect în regulă; prezinți din Studio |

**Încearcă tu — publicarea (15–20 min)**  
- [ ] Hotărât cu profesorul: Privat / Public / Nu publici  
- [ ] Dacă publici: testat în Player  
- [ ] Notat link-ul/pasul într-un loc sigur

### 3) Prezentarea (3–5 minute)
| # | Ce arăți | Timp |
|---|----------|------|
| 1 | **Demo:** joci jocul, explici ce se întâmplă | 1–2 min |
| 2 | **Un script:** deschizi codul, explici **în cuvinte simple** | 1 min |
| 3 | **O regulă de securitate:** de ce serverul decide | 30 s |
| 4 | **DataStore:** ce salvezi, de ce `pcall` | 30 s |
| 5 | **Un bug rezolvat:** cum l-ai găsit | 30 s |

**Sfaturi:**
- Vorbește **încet** și clar.  
- Arată pe ecran în timp ce vorbești.  
- Dacă te blochezi: „Hai să arăt…" și continui.  
- Nu citi cod rând cu rând; explică **ideea**.

**Formula pentru cod:** *„Acest script … când … și atunci …"*  
Ex.: *„Acest script salvează monedele când jucătorul iese și le încarcă când intră."*

### 4) Când asculți prezentările
- Aplaudă, fii respectuos.  
- Pregătește **o întrebare** sau **un compliment** specific.  
- Folosește formula: *„Mi-a plăcut…, mă întreb…"*

### 5) Reflecție: M1 → M4
Completează:

| Modul | Ce am învățat | Cel mai greu | Cel mai mândru de |
|-------|---------------|--------------|-------------------|
| **M1 · Studio** | | | |
| **M2 · Script Starter** | | | |
| **M3 · Game Logic** | | | |
| **M4 · Game Creator** | | | |

**Întrebări:**
- Ce poți face acum, ce nu puteai la început?  
- Ce concepte (variabilă, funcție, eveniment, server/client, DataStore) le-ai înțeles cel mai bine?  
- Ce ai vrea să înveți mai departe?

### 6) Ce urmează?
| Idee | Ce înveți |
|------|-----------|
| Mai multe niveluri | design, progresie |
| Multiplayer | cum interacționează jucătorii |
| Interfețe mai avansate | UI, animații |
| Un joc cu povestire | dialoguri, misiuni |
| Alt limbaj (Python, C++) | programare în afara Roblox |
| Arte 3D (Blender, Tinkercad) | modele proprii |

> Cele mai bune reguli: **fă proiecte mici**, **termină-le**, **învață din greșeli**.

---

## Greșeli frecvente
1. **Prezentarea necitită/necunoscută** — te antrenezi înainte.  
2. **Citești codul rând cu rând** — explici ideea.  
3. **Publici fără acord** — respecți regulile.  
4. **Nu testezi în Player** — poți avea surprize.  
5. **Uiți numele final al DataStore-ului.**  
6. **Te grăbești** — vorbește încet.  
7. **Judeci prezentările altora** — oferi feedback politicos.  
8. **Nu salvezi `_FINAL`** după ultimele schimbări.  
9. **Compari** — fiecare a învățat în ritmul lui.  
10. **Te oprești aici** — un joc terminat e începutul, nu sfârșitul.
