## Ce acoperă Modulul 4

| Concept | Unde | Notă |
|---------|------|------|
| ModuleScript | L1 | Întâi organizezi codul — apoi DataStore în modul |
| DataStore | L2 | **Minim** = 1 valoare (ex. monede max); logica preferabil într-un ModuleScript |
| NPC simplu | L3 | Mișcare sau atingere → −1 viață |
| Inventar **sau** shop | L4 | **Reluare M3 L4:** serverul verifică plata / achiziția, nu crede clientul oarbă |
| Polish + playtest + debug | L5–L7 | |
| Publish pe Roblox | L8–L10 | Cont / permisiuni: verifică politica școlii |

**De ce ModuleScript înainte de DataStore:** practica standard e să pui logica grea (salvare) într-un modul; întâi știi cum arată un ModuleScript, apoi îl folosești.
