# Tinkercad 3D — Curriculum Code Kids Play

**5 module × 10 lecții = 50 lecții**  
**Vârstă orientativă:** 8–10 (M1–M4) · M5 Design Pro = **10+** / Complet opțional sub 12  
**Durată oră CKP:** ~**2 ore** (nucleu PDF 45–60 min = Minim; restul = Complet + prezentare)  
**Print 3D:** după ore, nu în timpul lecției  
**Status site:** module + titluri în `mockData` (`m29`–`m33`) · **50 lecții `.md`** în `lectii/tinkercad/modul1–5/` (sincron `app/content/`)

### Badge-uri

| Modul | Nume | Badge |
|-------|------|--------|
| 1 | Bazele Tinkercad | **Shape Starter** |
| 2 | Obiecte utile | **Object Maker** |
| 3 | Creativ și mecanic | **Motion Maker** |
| 4 | Orașul nostru | **City Builder** |
| 5 | Avansat și proiectare tehnică | **Design Pro** |

### Ordine (înghețată)

```
Shape Starter → Object Maker → Motion Maker → City Builder → Design Pro
```

Traseu tipic 8–10: **M1→M4**.  
Traseu complet / avansați: **+ M5**.

### Format lecție (~120 min)

1. Warm-up / recap (10–15)  
2. Demo scurt (10–15)  
3. **Minim** — obiectul lecției, salvat (45–55)  
4. **Complet / Bonus** (25–35)  
5. Prezentare scurtă + salvare (10–15)  

Fiecare lecție se închide cu un **obiect finalizat și salvat**.
