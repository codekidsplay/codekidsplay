# LECȚIA 1 — Introducere + primul program
**Modulul 1 · Bazele C++ · Cam 2 ore**  
**Code Kids Play · Junior Coder**

> La final: IDE deschis, program care afișează text cu `cout`, salvat ca `.cpp`.

### Schelet
```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Salut!" << endl;
    return 0;
}
```
**IDE:** Code::Blocks sau VS Code + compiler (g++).

## Ideea principală
C++ = text pe care computerul îl **compilează**, apoi rulează.
`cout` = scrie pe ecran (ca `print` / „spune” din Scratch).

## Proiect / exerciții de finalizat AZI
- [ ] Programul compilează fără erori
- [ ] Afișezi ≥2 rânduri de text
- [ ] Folosești `\n` sau `endl`
- [ ] Fișier salvat: `Nume_L1.cpp`
- [ ] Card „Despre mine” (nume, vârstă, hobby — pe ecran)

**Gata când:** rulezi programul și se vede cardul tău.

## Bonus / Provocare (dacă ai terminat)
- [ ] Escape: `\t`, `\"`
- [ ] 3 mesaje colorate pe foaie (ce ai scrie dacă ar fi culori)
- [ ] Greșești voită o literă și citești mesajul de eroare

## Temă
Adaugă un desen ASCII mic (3–5 rânduri) acasă.
