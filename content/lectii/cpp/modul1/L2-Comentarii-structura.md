# LECȚIA 2 — Comentarii + structura programului
**Modulul 1 · Bazele C++ · Cam 2 ore**  
**Code Kids Play · Junior Coder**

> La final: înțelegi `#include`, `main`, comentarii; codul tău e comentat corect.


---

## Planul orei (120 minute)

| Minute | Ce facem |
|--------|----------|
| 0–15 | Recap L1 + ce e un „program complet” |
| 15–40 | `#include`, `namespace`, `main`, `return 0` |
| 40–70 | Comentarii `//` și `/* */` |
| 70–105 | Rescrii L1 cu comentarii + structură curată |
| 105–120 | Verificare + temă |

---

## Ideea principală
Comentariile sunt pentru **oameni**. Compilerul le ignoră.
Fără `main` → nu are unde să înceapă.

## Proiect / exerciții de finalizat AZI
- [ ] Cel puțin 3 comentarii utile (nu „spam”)
- [ ] Explici pe foaie ce face `#include <iostream>`
- [ ] Programul are `main` + `return 0`
- [ ] Compilează
- [ ] Nume fișier: `Nume_L2.cpp`

**Gata când:** un coleg citește comentariile și înțelege programul.

## Bonus / Provocare (dacă ai terminat)
- [ ] Comentariu pe mai multe linii `/* */`
- [ ] TODO: 1 idee pentru L3 pe foaie
- [ ] Ștergi `using namespace std;` și folosești `std::cout` (preview)

## Temă
Comentează un program vechi (L1) dacă nu l-ai făcut azi.
