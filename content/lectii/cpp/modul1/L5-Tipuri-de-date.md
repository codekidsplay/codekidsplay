# LECȚIA 5 — Tipuri de date
**Modulul 1 · Bazele C++ · Cam 2 ore**  
**Code Kids Play · Junior Coder**

> La final: folosești `double`, `char`, `bool`, `string` într-un program mic.


---

## Planul orei (120 minute)

| Minute | Ce facem |
|--------|----------|
| 0–20 | De ce nu doar `int`? |
| 20–50 | `double`, `char`, `bool`, `string` (+ `#include <string>`) |
| 50–70 | ASCII pe scurt (`char`) |
| 70–105 | Proiect: convertor / card cu tipuri mixte |
| 105–120 | Temă |

---

## Ideea principală
`double` = zecimale · `char` = un caracter · `bool` = true/false · `string` = text.

## Proiect / exerciții de finalizat AZI
- [ ] Cel puțin 4 tipuri diferite în program
- [ ] Citești un `double` (ex. preț / înălțime)
- [ ] Afișezi un `string` (nume)
- [ ] Un `bool` afișat (0/1 sau true/false)
- [ ] `Nume_L5.cpp`

**Gata când:** programul amestecă tipurile fără erori de compilare.

## Bonus / Provocare (dacă ai terminat)
- [ ] Media a 3 note cu `double`
- [ ] Afișezi codul ASCII al unui `char`
- [ ] Concatenezi 2 string-uri

## Temă
Pe foaie: ce tip alegi pentru vârstă / preț / inițială / „e elev?”.
