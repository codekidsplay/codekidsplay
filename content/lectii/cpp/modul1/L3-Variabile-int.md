# LECȚIA 3 — Variabile `int`
**Modulul 1 · Bazele C++ · Cam 2 ore**  
**Code Kids Play · Junior Coder**

> La final: declari `int`, afișezi valori, faci o sumă pe ecran.

### Exemplu
```cpp
int a = 5;
int b = 3;
int suma = a + b;
cout << "Suma = " << suma << endl;
```

---

## Planul orei (120 minute)

| Minute | Ce facem |
|--------|----------|
| 0–15 | Ce e o variabilă (cutie cu nume) |
| 15–40 | Declarare, atribuire, reguli de nume |
| 40–60 | `const` — valoare care nu se schimbă |
| 60–100 | Proiect: calculator sumă (valori în cod) |
| 100–120 | Erori tipice + temă |

---

## Ideea principală
`int varsta = 12;` — cutia `varsta` ține un întreg.
Nume: fără spații, nu începe cu cifră.

## Proiect / exerciții de finalizat AZI
- [ ] ≥3 variabile `int` cu nume clare
- [ ] Afișezi valorile cu `cout`
- [ ] Calculezi o sumă (sau diferență) într-o variabilă
- [ ] Cel puțin un `const` (ex. `const int ZILE = 7`)
- [ ] `Nume_L3.cpp` compilează

**Gata când:** pe ecran apar numerele și rezultatul sumei.

## Bonus / Provocare (dacă ai terminat)
- [ ] Produsul a 3 numere
- [ ] Greșeală: folosești variabila înainte să o declari — vezi eroarea
- [ ] Afișezi „Varsta mea este: ” + număr pe același rând

## Temă
Schimbă valorile și recompilează — verifică rezultatul.
