## Ideea principală
`cin >> x;` — citește în variabila `x`.
`%` = rest (ex. 10 % 3 = 1).

## Proiect / exerciții de finalizat AZI
- [ ] Citești ≥2 numere cu `cin`
- [ ] Afișezi sumă și produs
- [ ] Afișezi cât și rest (`/` și `%`)
- [ ] Mesaje clare pe ecran („Introdu a: ”)
- [ ] `Nume_L4.cpp`

**Gata când:** testezi cu 2 seturi de numere diferite.

## Bonus / Provocare (dacă ai terminat)
- [ ] Media a 3 note (încă pe `int` — observi limitarea)
- [ ] Verifici dacă un număr e par (`% 2 == 0`) — preview if
- [ ] Problema tip: ultima cifră a unui număr (`n % 10`)
